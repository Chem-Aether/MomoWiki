## 4. PBS 常用命令

PBS 系统常见实现包括 PBS Pro、OpenPBS、Torque。命令大体相似，但不同集群参数可能略有差异。

### 查看队列：`qstat`

```bash
qstat
qstat -u $USER
qstat -f 123456
```

常用参数：

| 参数 | 说明 |
| --- | --- |
| `-u 用户名` | 查看指定用户任务 |
| `-f 作业ID` | 查看作业详细信息 |
| `-Q` | 查看队列信息 |
| `-q` | 查看队列摘要 |

常见状态：

| 状态 | 说明 |
| --- | --- |
| `Q` | 排队 |
| `R` | 运行中 |
| `C` | 完成 |
| `H` | 挂起 |
| `E` | 退出中 |

### 提交任务：`qsub`

```bash
qsub job.pbs
```

示例脚本：

```bash
#!/bin/bash
#PBS -N test_job
#PBS -q batch
#PBS -l nodes=1:ppn=4
#PBS -l mem=8gb
#PBS -l walltime=01:00:00
#PBS -o job.out
#PBS -e job.err

cd $PBS_O_WORKDIR
hostname
date
python script.py
```

常用 `#PBS` 参数：

| 参数 | 说明 |
| --- | --- |
| `-N` | 任务名称 |
| `-q` | 队列名称 |
| `-l nodes=1:ppn=4` | 申请 1 个节点，每节点 4 核 |
| `-l select=1:ncpus=4:mem=8gb` | PBS Pro 常见资源写法 |
| `-l mem=8gb` | 申请内存 |
| `-l walltime=01:00:00` | 最大运行时间 |
| `-o` | 标准输出文件 |
| `-e` | 标准错误文件 |

PBS Pro 风格示例：

```bash
#!/bin/bash
#PBS -N gpu_job
#PBS -q gpu
#PBS -l select=1:ncpus=8:ngpus=1:mem=32gb
#PBS -l walltime=04:00:00
#PBS -o gpu.out
#PBS -e gpu.err

cd $PBS_O_WORKDIR
nvidia-smi
python train.py
```

### 删除任务：`qdel`

```bash
qdel 123456
```

### 查看节点：`pbsnodes`

```bash
pbsnodes
pbsnodes -a
pbsnodes -l
```

常用参数：

| 参数 | 说明 |
| --- | --- |
| `-a` | 查看全部节点 |
| `-l` | 查看异常、离线或不可用节点 |

## 6. PBS 交互式任务

不同 PBS 集群写法可能不同，常见示例：

```bash
qsub -I -q batch -l nodes=1:ppn=4,mem=8gb,walltime=01:00:00
```

PBS Pro 风格：

```bash
qsub -I -q batch -l select=1:ncpus=4:mem=8gb -l walltime=01:00:00
```
