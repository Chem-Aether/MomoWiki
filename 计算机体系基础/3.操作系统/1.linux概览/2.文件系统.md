# 02. 文件系统管理：移动、复制、新建、删除

本节介绍 Linux 中最常见的文件和目录操作。初学者最容易出错的是路径和删除命令，执行前请先确认当前位置。

## 1. 路径基础

### 查看当前目录：`pwd`

```bash
pwd
```

`pwd` 会显示当前所在目录的绝对路径。

### 切换目录：`cd`

```bash
cd /home/user
cd ..
cd ~
cd -
```

常见用法：

| 命令 | 说明 |
| --- | --- |
| `cd /path/to/dir` | 切换到指定目录 |
| `cd ..` | 返回上一级目录 |
| `cd ~` | 回到当前用户家目录 |
| `cd -` | 回到上一次所在目录 |

### 路径类型

| 类型 | 示例 | 说明 |
| --- | --- | --- |
| 绝对路径 | `/home/user/data.txt` | 从根目录 `/` 开始 |
| 相对路径 | `data.txt`、`../data` | 相对当前目录 |
| 家目录 | `~` | 当前用户的 home 目录 |

## 2. 查看文件和目录

### `ls`

列出目录内容。

```bash
ls
ls -l
ls -lh
ls -la
ls /home/user
```

常用参数：

| 参数 | 说明 |
| --- | --- |
| `-l` | 长格式显示权限、用户、大小、时间 |
| `-h` | 与 `-l` 搭配，大小以易读单位显示 |
| `-a` | 显示隐藏文件 |
| `-t` | 按修改时间排序 |
| `-r` | 反向排序 |

常用组合：

```bash
ls -lh
ls -lah
ls -ltr
```

### `tree`

以树状结构显示目录，可能需要安装。

```bash
tree
tree -L 2
```

参数：

| 参数 | 说明 |
| --- | --- |
| `-L 2` | 只显示 2 层目录 |

## 3. 新建文件和目录

### `touch`

创建空文件，或更新文件修改时间。

```bash
touch notes.txt
touch a.txt b.txt
```

### `mkdir`

创建目录。

```bash
mkdir data
mkdir -p project/src/scripts
```

常用参数：

| 参数 | 说明 |
| --- | --- |
| `-p` | 自动创建不存在的父目录 |

## 4. 查看文件内容

### `cat`

一次性输出整个文件。

```bash
cat file.txt
cat a.txt b.txt
```

适合查看短文件。

### `less`

分页查看文件。

```bash
less large.log
```

常用按键：

| 按键 | 说明 |
| --- | --- |
| `空格` | 下一页 |
| `b` | 上一页 |
| `/关键词` | 搜索 |
| `n` | 下一个搜索结果 |
| `q` | 退出 |

### `head` 和 `tail`

查看文件开头或结尾。

```bash
head file.txt
head -n 20 file.txt
tail file.txt
tail -n 50 file.txt
tail -f app.log
```

常用参数：

| 参数 | 说明 |
| --- | --- |
| `-n 数字` | 指定显示行数 |
| `tail -f` | 持续追踪文件新增内容，常用于日志 |

## 5. 复制文件和目录

### `cp`

复制文件或目录。

```bash
cp source.txt target.txt
cp source.txt /tmp/
cp -r dir1 dir2
cp -i source.txt target.txt
```

常用参数：

| 参数 | 说明 |
| --- | --- |
| `-r` | 递归复制目录 |
| `-i` | 覆盖前询问 |
| `-v` | 显示复制过程 |
| `-p` | 保留权限、时间等属性 |

示例：

```bash
cp -rv raw_data backup_data
```

## 6. 移动与重命名

### `mv`

移动文件，也可用于重命名。

```bash
mv old.txt new.txt
mv file.txt /tmp/
mv dir1 /data/project/
mv -i a.txt b.txt
```

常用参数：

| 参数 | 说明 |
| --- | --- |
| `-i` | 覆盖前询问 |
| `-v` | 显示移动过程 |

重命名示例：

```bash
mv result_old.txt result_final.txt
```

移动示例：

```bash
mv result_final.txt ./outputs/
```

## 7. 删除文件和目录

### `rm`

删除文件或目录。此命令危险，Linux 默认没有回收站。

```bash
rm file.txt
rm -i file.txt
rm -r old_dir
rm -rf old_dir
```

常用参数：

| 参数 | 说明 |
| --- | --- |
| `-i` | 删除前逐个询问 |
| `-r` | 递归删除目录 |
| `-f` | 强制删除，不提示 |
| `-v` | 显示删除过程 |

安全建议：

```bash
ls old_dir
rm -ri old_dir
```

初学者慎用：

```bash
rm -rf *
rm -rf /path
```

执行前务必用 `pwd` 和 `ls` 确认当前位置和目标。

### `rmdir`

删除空目录。

```bash
rmdir empty_dir
```

如果目录不为空，`rmdir` 会失败，因此比 `rm -r` 更安全。

## 8. 查找文件

### `find`

按名称、类型、大小、时间查找文件。

```bash
find . -name "*.txt"
find /home/user -type f -name "*.log"
find . -type d -name "results"
find . -size +1G
```

常用条件：

| 条件 | 说明 |
| --- | --- |
| `-name` | 按名称查找 |
| `-type f` | 查找普通文件 |
| `-type d` | 查找目录 |
| `-size +1G` | 查找大于 1GB 的文件 |
| `-mtime -7` | 查找 7 天内修改过的文件 |

### `locate`

通过索引快速查找文件，结果可能不是实时的。

```bash
locate filename
```

更新索引通常需要管理员权限：

```bash
sudo updatedb
```

## 9. 搜索文本

### `grep`

在文件中搜索文本。

```bash
grep "error" app.log
grep -n "error" app.log
grep -r "main" ./src
grep -i "warning" app.log
```

常用参数：

| 参数 | 说明 |
| --- | --- |
| `-n` | 显示行号 |
| `-r` | 递归搜索目录 |
| `-i` | 忽略大小写 |
| `-v` | 反向匹配，显示不包含关键词的行 |

## 10. 链接文件

### `ln`

创建硬链接或软链接。

```bash
ln file.txt hard_link.txt
ln -s /data/project project_link
```

常用参数：

| 参数 | 说明 |
| --- | --- |
| `-s` | 创建软链接，也叫符号链接 |

软链接类似快捷方式，HPC 和服务器上很常用。

## 11. 打包与压缩

### `tar`

打包或解包 `.tar`、`.tar.gz` 文件。

```bash
tar -cvf archive.tar mydir
tar -xvf archive.tar
tar -czvf archive.tar.gz mydir
tar -xzvf archive.tar.gz
```

常用参数：

| 参数 | 说明 |
| --- | --- |
| `-c` | 创建归档 |
| `-x` | 解包 |
| `-v` | 显示过程 |
| `-f` | 指定文件名 |
| `-z` | 使用 gzip 压缩或解压 |

## 12. 文件操作常用组合

查看当前目录大小：

```bash
du -sh .
```

找出大文件：

```bash
find . -type f -size +1G
```

按大小查看当前目录内容：

```bash
du -h --max-depth=1 . | sort -h
```

安全删除目录：

```bash
pwd
ls target_dir
rm -ri target_dir
```
