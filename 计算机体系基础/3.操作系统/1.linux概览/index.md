## 阅读建议

- 初学者先掌握 `pwd`、`ls`、`cd`、`cp`、`mv`、`rm`、`cat`、`less`、`grep`、`ssh`、`vim` 这些高频命令。
- 在服务器或集群上操作时，删除文件、修改权限、提交作业前要先确认路径和参数。
- 遇到命令不会用时，可以使用：

```bash
命令 --help
man 命令
```

示例：

```bash
ls --help
man ssh
```

`man` 页面中按 `q` 退出，按 `/关键词` 搜索。
