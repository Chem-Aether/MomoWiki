# 03. HPC 集群任务调度：Slurm 与 PBS

HPC 集群通常由登录节点和计算节点组成。用户在登录节点编写脚本、提交任务，调度系统再把任务分配到计算节点运行。常见调度系统有 Slurm 和 PBS。不同集群可能只安装其中一种。

## 1. HPC 使用基本原则

- 不要在登录节点上直接运行大型计算任务。
- 使用调度命令提交任务。
- 提交前确认申请的 CPU、内存、GPU、运行时间是否合理。
- 任务输出和错误日志要保存，方便排查。
- 大量小文件和频繁读写可能影响共享文件系统性能。

## 2. Slurm 常用命令

### 查看分区和节点：`sinfo`

```bash
sinfo
sinfo -N
sinfo -p gpu
```

常用参数：

| 参数 | 说明 |
| --- | --- |
| `-N` | 按节点显示 |
| `-p 分区名` | 只查看指定分区 |
| `-l` | 显示更详细信息 |

常见字段：

| 字段 | 说明 |
| --- | --- |
| `PARTITION` | 分区名 |
| `AVAIL` | 分区是否可用 |
| `TIMELIMIT` | 最大运行时间 |
| `NODES` | 节点数量 |
| `STATE` | 节点状态 |
| `NODELIST` | 节点列表 |

### 查看队列任务：`squeue`

```bash
squeue
squeue -u $USER
squeue -j 123456
```

常用参数：

| 参数 | 说明 |
| --- | --- |
| `-u 用户名` | 查看指定用户任务 |
| `-j 作业ID` | 查看指定作业 |
| `-p 分区名` | 查看指定分区任务 |

常见状态：

| 状态 | 说明 |
| --- | --- |
| `PD` | 排队等待 |
| `R` | 正在运行 |
| `CG` | 即将完成 |
| `CD` | 已完成 |
| `F` | 失败 |
| `TO` | 超时 |

### 提交批处理任务：`sbatch`

```bash
sbatch job.slurm
```

示例脚本：

```bash
#!/bin/bash
#SBATCH --job-name=test_job
#SBATCH --partition=compute
#SBATCH --nodes=1
#SBATCH --ntasks=1
#SBATCH --cpus-per-task=4
#SBATCH --mem=8G
#SBATCH --time=01:00:00
#SBATCH --output=slurm-%j.out
#SBATCH --error=slurm-%j.err

hostname
date
python script.py
```

常用 `#SBATCH` 参数：

| 参数 | 说明 |
| --- | --- |
| `--job-name` | 任务名称 |
| `--partition` | 使用的分区 |
| `--nodes` | 节点数量 |
| `--ntasks` | 任务进程数，MPI 常用 |
| `--cpus-per-task` | 每个任务使用的 CPU 线程数 |
| `--mem` | 申请内存 |
| `--time` | 最大运行时间，格式如 `HH:MM:SS` |
| `--output` | 标准输出日志 |
| `--error` | 标准错误日志 |
| `--gres=gpu:1` | 申请 GPU，具体写法依集群配置而定 |

GPU 示例：

```bash
#!/bin/bash
#SBATCH --job-name=gpu_job
#SBATCH --partition=gpu
#SBATCH --nodes=1
#SBATCH --ntasks=1
#SBATCH --cpus-per-task=8
#SBATCH --mem=32G
#SBATCH --gres=gpu:1
#SBATCH --time=04:00:00
#SBATCH --output=%x-%j.out

nvidia-smi
python train.py
```

### 取消任务：`scancel`

```bash
scancel 123456
scancel -u $USER
```

常用参数：

| 参数 | 说明 |
| --- | --- |
| `作业ID` | 取消指定作业 |
| `-u 用户名` | 取消指定用户所有作业，慎用 |

### 查看任务详细信息：`scontrol`

```bash
scontrol show job 123456
scontrol show node node001
```

用途：

| 命令 | 说明 |
| --- | --- |
| `scontrol show job` | 查看任务申请资源、状态、节点等 |
| `scontrol show node` | 查看节点详细状态 |

### 查看历史任务：`sacct`

```bash
sacct
sacct -j 123456
sacct -u $USER
sacct -j 123456 --format=JobID,JobName,State,Elapsed,MaxRSS
```

常用参数：

| 参数 | 说明 |
| --- | --- |
| `-j` | 指定作业 ID |
| `-u` | 指定用户 |
| `--format` | 指定输出字段 |

## 3. Slurm 交互式任务

### `srun`

申请资源并交互运行命令。

```bash
srun --partition=compute --cpus-per-task=4 --mem=8G --time=01:00:00 --pty bash
```

GPU 交互示例：

```bash
srun --partition=gpu --gres=gpu:1 --cpus-per-task=8 --mem=32G --time=02:00:00 --pty bash
```

进入计算节点后再运行程序。

## 4. PBS 常用命令

PBS 系统常见实现包括 PBS Pro、OpenPBS、Torque。命令大体相似，但不同集群参数可能略有差异。

### 查看队列：`qstat`

```bash
qstat
qstat -u $USER
qstat -f 123456
```

常用参数：

| 参数 | 说明 |
| --- | --- |
| `-u 用户名` | 查看指定用户任务 |
| `-f 作业ID` | 查看作业详细信息 |
| `-Q` | 查看队列信息 |
| `-q` | 查看队列摘要 |

常见状态：

| 状态 | 说明 |
| --- | --- |
| `Q` | 排队 |
| `R` | 运行中 |
| `C` | 完成 |
| `H` | 挂起 |
| `E` | 退出中 |

### 提交任务：`qsub`

```bash
qsub job.pbs
```

示例脚本：

```bash
#!/bin/bash
#PBS -N test_job
#PBS -q batch
#PBS -l nodes=1:ppn=4
#PBS -l mem=8gb
#PBS -l walltime=01:00:00
#PBS -o job.out
#PBS -e job.err

cd $PBS_O_WORKDIR
hostname
date
python script.py
```

常用 `#PBS` 参数：

| 参数 | 说明 |
| --- | --- |
| `-N` | 任务名称 |
| `-q` | 队列名称 |
| `-l nodes=1:ppn=4` | 申请 1 个节点，每节点 4 核 |
| `-l select=1:ncpus=4:mem=8gb` | PBS Pro 常见资源写法 |
| `-l mem=8gb` | 申请内存 |
| `-l walltime=01:00:00` | 最大运行时间 |
| `-o` | 标准输出文件 |
| `-e` | 标准错误文件 |

PBS Pro 风格示例：

```bash
#!/bin/bash
#PBS -N gpu_job
#PBS -q gpu
#PBS -l select=1:ncpus=8:ngpus=1:mem=32gb
#PBS -l walltime=04:00:00
#PBS -o gpu.out
#PBS -e gpu.err

cd $PBS_O_WORKDIR
nvidia-smi
python train.py
```

### 删除任务：`qdel`

```bash
qdel 123456
```

### 查看节点：`pbsnodes`

```bash
pbsnodes
pbsnodes -a
pbsnodes -l
```

常用参数：

| 参数 | 说明 |
| --- | --- |
| `-a` | 查看全部节点 |
| `-l` | 查看异常、离线或不可用节点 |

## 5. Slurm 与 PBS 命令对照

| 功能 | Slurm | PBS |
| --- | --- | --- |
| 查看分区/节点 | `sinfo` | `pbsnodes` |
| 查看队列 | `squeue` | `qstat` |
| 提交任务 | `sbatch` | `qsub` |
| 删除任务 | `scancel` | `qdel` |
| 查看任务详情 | `scontrol show job` | `qstat -f` |
| 交互式任务 | `srun --pty bash` | `qsub -I` |

## 6. PBS 交互式任务

不同 PBS 集群写法可能不同，常见示例：

```bash
qsub -I -q batch -l nodes=1:ppn=4,mem=8gb,walltime=01:00:00
```

PBS Pro 风格：

```bash
qsub -I -q batch -l select=1:ncpus=4:mem=8gb -l walltime=01:00:00
```

## 7. 作业排错建议

查看日志：

```bash
cat slurm-123456.out
less job.err
tail -f job.out
```

常见问题：

| 问题 | 排查方向 |
| --- | --- |
| 一直排队 | 分区繁忙、资源申请过大、账户限制 |
| 任务很快失败 | 查看 `.err` 或 Slurm/PBS 输出日志 |
| 超时失败 | 增加运行时间或优化程序 |
| 内存不足 | 增加 `--mem` 或 `mem=` |
| GPU 不可见 | 确认申请了 GPU 分区和 GPU 资源 |
