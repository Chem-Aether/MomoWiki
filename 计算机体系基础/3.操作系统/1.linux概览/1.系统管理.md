# 系统命令：硬件、节点、资源查看

本节介绍如何查看 Linux 系统信息、CPU、内存、磁盘、GPU、进程，以及 HPC 集群节点状态。

## 1. 系统基本信息

### `uname`

查看内核和系统架构信息。

```bash
uname
uname -a
uname -r
uname -m
```

常用参数：

| 参数 | 说明 |
| --- | --- |
| `-a` | 显示全部系统信息 |
| `-r` | 显示内核版本 |
| `-m` | 显示机器架构，如 `x86_64`、`aarch64` |

### `hostname`

查看或设置主机名。

```bash
hostname
hostname -I
```

常用参数：

| 参数 | 说明 |
| --- | --- |
| `-I` | 显示本机 IP 地址 |
| `-f` | 显示完整域名，若系统配置了 DNS |

### `lsb_release`

查看 Linux 发行版信息，常见于 Ubuntu、Debian 系统。

```bash
lsb_release -a
```

如果命令不存在，可以使用：

```bash
cat /etc/os-release
```

## 2. CPU 信息

### `lscpu`

查看 CPU 型号、核心数、线程数、架构等。

```bash
lscpu
```

重点字段：

| 字段 | 说明 |
| --- | --- |
| `Architecture` | CPU 架构 |
| `CPU(s)` | 总逻辑 CPU 数 |
| `Core(s) per socket` | 每个 CPU 插槽的物理核心数 |
| `Thread(s) per core` | 每个核心的线程数 |
| `Model name` | CPU 型号 |

### `/proc/cpuinfo`

查看更详细的 CPU 信息。

```bash
cat /proc/cpuinfo
grep "model name" /proc/cpuinfo
grep -c "processor" /proc/cpuinfo
```

说明：

| 命令 | 含义 |
| --- | --- |
| `grep "model name"` | 查看 CPU 型号 |
| `grep -c "processor"` | 统计逻辑 CPU 数 |

## 3. 内存信息

### `free`

查看内存使用情况。

```bash
free
free -h
free -m
```

常用参数：

| 参数 | 说明 |
| --- | --- |
| `-h` | 以人类可读单位显示，如 GiB、MiB |
| `-m` | 以 MB 为单位显示 |
| `-g` | 以 GB 为单位显示 |

示例输出中的常见字段：

| 字段 | 说明 |
| --- | --- |
| `total` | 总内存 |
| `used` | 已使用内存 |
| `free` | 完全空闲内存 |
| `buff/cache` | 被缓存占用但可回收的内存 |
| `available` | 应用程序大约还可用的内存 |

### `/proc/meminfo`

查看更详细的内存信息。

```bash
cat /proc/meminfo
grep MemTotal /proc/meminfo
grep MemAvailable /proc/meminfo
```

## 4. 磁盘与文件系统占用

### `df`

查看文件系统磁盘使用情况。

```bash
df
df -h
df -h /home
```

常用参数：

| 参数 | 说明 |
| --- | --- |
| `-h` | 以易读单位显示 |
| `-T` | 显示文件系统类型 |
| `-i` | 显示 inode 使用情况 |

### `du`

查看目录或文件占用空间。

```bash
du -h file.txt
du -sh mydir
du -h --max-depth=1 .
```

常用参数：

| 参数 | 说明 |
| --- | --- |
| `-h` | 以易读单位显示 |
| `-s` | 只显示总计 |
| `--max-depth=1` | 只统计当前目录下一层 |

查找当前目录下占空间最大的文件或目录：

```bash
du -h --max-depth=1 . | sort -h
```

## 5. 磁盘型号与硬件信息

### `lsblk`

查看块设备、磁盘、分区和挂载点。

```bash
lsblk
lsblk -f
lsblk -o NAME,SIZE,TYPE,FSTYPE,MOUNTPOINT,MODEL
```

常用参数：

| 参数 | 说明 |
| --- | --- |
| `-f` | 显示文件系统类型和 UUID |
| `-o` | 指定输出列 |

### `lshw`

查看硬件信息。部分系统需要管理员权限。

```bash
sudo lshw -short
sudo lshw -class disk
sudo lshw -class memory
```

### `dmidecode`

查看 BIOS、内存条、主板等硬件信息，通常需要 root 权限。

```bash
sudo dmidecode -t memory
sudo dmidecode -t system
```

常见类型：

| 类型 | 说明 |
| --- | --- |
| `memory` | 内存条信息 |
| `system` | 机器厂商、型号 |
| `bios` | BIOS 信息 |

## 6. 进程与系统负载

### `top`

实时查看进程、CPU、内存占用。

```bash
top
```

常用按键：

| 按键 | 说明 |
| --- | --- |
| `q` | 退出 |
| `P` | 按 CPU 占用排序 |
| `M` | 按内存占用排序 |
| `k` | 结束某个进程，需要输入 PID |

### `htop`

更友好的实时进程查看工具，可能需要安装。

```bash
htop
```

### `ps`

查看当前进程快照。

```bash
ps
ps aux
ps aux | grep python
```

常用形式：

| 命令 | 说明 |
| --- | --- |
| `ps` | 查看当前终端相关进程 |
| `ps aux` | 查看系统所有进程 |
| `grep python` | 过滤包含 python 的进程 |

## 7. GPU 信息

### NVIDIA GPU：`nvidia-smi`

查看 NVIDIA GPU 型号、显存、温度、运行进程。

```bash
nvidia-smi
nvidia-smi -L
watch -n 1 nvidia-smi
```

常用参数：

| 参数 | 说明 |
| --- | --- |
| `-L` | 只列出 GPU 型号 |
| `watch -n 1` | 每 1 秒刷新一次命令输出 |

## 8. 集群节点查看

不同 HPC 集群可能使用不同调度系统。常见为 Slurm 或 PBS。

### Slurm 节点信息

```bash
sinfo
sinfo -N
sinfo -Nel
scontrol show node
```

常用命令：

| 命令 | 说明 |
| --- | --- |
| `sinfo` | 查看分区和节点总体状态 |
| `sinfo -N` | 按节点显示 |
| `sinfo -Nel` | 显示更详细的节点信息 |
| `scontrol show node` | 显示节点详细配置 |

常见节点状态：

| 状态 | 说明 |
| --- | --- |
| `idle` | 空闲 |
| `alloc` | 已分配 |
| `mix` | 部分资源被占用 |
| `down` | 不可用 |
| `drain` | 正在排空，不再接收新任务 |

### PBS 节点信息

```bash
pbsnodes
pbsnodes -a
pbsnodes -l
```

常用参数：

| 参数 | 说明 |
| --- | --- |
| `-a` | 查看所有节点详细信息 |
| `-l` | 查看离线或不可用节点 |

## 9. 综合排查示例

查看机器基本情况：

```bash
hostname
cat /etc/os-release
lscpu
free -h
df -h
lsblk -o NAME,SIZE,TYPE,FSTYPE,MOUNTPOINT,MODEL
```

查看哪个进程占用资源较高：

```bash
top
ps aux | sort -nrk 3 | head
ps aux | sort -nrk 4 | head
```

说明：

| 命令 | 含义 |
| --- | --- |
| `sort -nrk 3` | 按第 3 列 CPU 占用倒序排序 |
| `sort -nrk 4` | 按第 4 列内存占用倒序排序 |
